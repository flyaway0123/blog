# Hello World

这是我的第一篇博客文章。

我一直想有一个属于自己的地方，用来记录技术、学习过程，以及一些值得留下来的思考。相比把内容分散在不同的平台上，我更希望这些文章能够以 Markdown 的形式保存在自己的仓库里，并且能够长期维护。

目前这个博客使用 AstroPaper 搭建，部署在 GitHub Pages 上。文章使用 Markdown 编写，代码和文章一起通过 Git 管理。

我希望以后这里不仅仅是一个展示页面，而是一个真正持续使用的个人知识库。

从这篇文章开始。
